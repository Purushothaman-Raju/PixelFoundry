# Pixel Foundry

Production Toolkit for Autodesk Maya

## Goal

A single dockable production workspace for Autodesk Maya.

## Principles

- One window.
- One workspace.
- No multiple tool windows.
- Modular architecture.
- Production-first workflow.
- Maya 2027 only.
